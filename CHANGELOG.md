# Changelog

## 1.0.0

- Bounded Linux CPU, RAM, disk and HTTPS network measurements using the Python standard library and available system tools.
- Local Markdown, JSON and CSV reports; private output permissions and no automatic report upload.
- Docker state comparison with explicit unavailable/pending states.
- Version-pinned Bash bootstrap with SHA256 verification, private temporary copies and signal forwarding.
- Offline regression tests and a node provisioning checklist.
